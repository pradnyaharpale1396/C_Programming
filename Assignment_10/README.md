This repository contains various C programs written to practice fundamental programming concepts such as functions, arithmetic operations, unit conversions, and mathematical calculations.

Programs Included
1) Calculate the area of a circle using the radius provided by the user.
Input: 5.3
Output: 88.2026

2) Calculate the area of a rectangle using the width and height provided by the user.
Input: 5.3, 9.78
Output: 51.834

3) Convert a distance from kilometers to meters.
Input: 5
Output: 5000

4) Convert a temperature from Fahrenheit to Celsius.
Input: 10
Output: -12.2222

5) Convert an area from square feet to square meters.
Input: 5
Output: 0.464515

How to Compile :
Open Command Prompt and navigate to the program folder.

gcc ProgramName.c -o Myexe
Example:

gcc Program1.c -o Myexe
gcc Program2.c -o Myexe
gcc Program3.c -o Myexe
gcc Program4.c -o Myexe
gcc Program5.c -o Myexe

How to Run :
Myexe
