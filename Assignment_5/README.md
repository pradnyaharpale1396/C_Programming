This repository contains various C programs written to practice fundamental programming concepts such as loops, functions, operators, conditional statements, and pattern printing.

Programs Included :
1) Identify the greatest number among three given numbers.
2) Determine whether a given year is a leap year.
3) Calculate and display a student's grade based on the entered marks.
4) Check whether a number is divisible by 3, divisible by 5, divisible by both, or divisible by neither.
5) Identify the type of a character (uppercase letter, lowercase letter, digit, or special character).

How to Compile :
Open Command Prompt and navigate to the program folder.

gcc ProgramName.c -o Myexe
Example:

gcc Program1.c -o Myexe
gcc Program2.c -o Myexe
gcc Program3.c -o Myexe
gcc Program4.c -o Myexe
gcc Program5.c -o Myexe

How to Run :
Myexe
