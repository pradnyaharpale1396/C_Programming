This repository contains various C programs written to practice fundamental programming concepts such as loops, functions, operators, conditional statements, and pattern printing.

Programs Included :
1) Calculate electricity bill for defined units consumed
2) Check admission eligibility if student 's marks are at least 60 and age is at at least 17 years
3) Calculate final Payable amount after applying discount
4) Accept 3 numbers representing three sides of a triangle. All side must be positive, sum of two sides must be greater than third side
5) Accept salary and years of service and determine its bonus

How to Compile :
Open Command Prompt and navigate to the program folder.

gcc ProgramName.c -o Myexe
Example:

gcc Program1.c -o Myexe
gcc Program2.c -o Myexe
gcc Program3.c -o Myexe
gcc Program4.c -o Myexe
gcc Program5.c -o Myexe

How to Run :
Myexe
